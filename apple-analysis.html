Apple Financial Analysis

An independent Excel project analyzing Apple’s financial statements and building forecasts for FY2026.

Independent project · Financial modeling · 2026
AAPLHistorical financial analysis and FY2026 scenarios
01 / The goal

Understand Apple’s performance beyond revenue

I built an independent financial analysis model in Excel to examine Apple’s historical financial performance, including revenue growth, operating expenses, margins, profitability, and earnings trends.

02 / My approach

From financial statements to a forecast

I organized FY2023–FY2025 historical information, calculated performance metrics, and used FY2026 year-to-date information and documented assumptions to develop full-year forecasts. I included source references so the model could be checked.

03 / Scenario analysis

Testing how different assumptions affect the forecast

The model includes downside, base, and upside scenarios. By changing forecast assumptions, I could compare how revenue, profitability, and earnings per share might change rather than relying on a single estimate.

04 / My financial dashboard

Comparing actual performance with forecasts

05 / Skills I developed

What I took away from this project

Working on this model helped me become more comfortable reading financial statements, building forecast assumptions, and seeing how those assumptions affect the results. I also practiced presenting financial data clearly through an Excel dashboard.
